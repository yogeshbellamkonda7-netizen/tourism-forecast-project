
# TourSight AI – Frontend

TourSight AI is a tourism intelligence web application that uses machine learning to predict tourism receipts from historical tourism and economic data.

This folder contains the React frontend of the project.

## Technologies

- React
- Vite
- Tailwind CSS
- JavaScript
- Lucide React

## Features

- Country-based tourism receipts prediction
- Prediction results and history
- Country comparison
- Machine learning model information
- Responsive dashboard interface

## Run Locally

```bash
npm install
npm run dev
````

The frontend communicates with the FastAPI backend for generating predictions.
